## Mise à jour du site

Les fichiers du site sont à la racine du dépôt (`index.html`, `style.css`, `script.js` et les images). GitHub Pages publie automatiquement la branche `main` depuis cette racine. Après l'envoi des modifications sur `main`, le site est mis à jour automatiquement.
